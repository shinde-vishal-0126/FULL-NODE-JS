01. What is Amazon S3?

Amazon S3 (Simple Storage Service) is a distributed, massively scalable object storage service designed to store and retrieve any volume of data from anywhere on the web with 99.999999999% (11 9s) durability.

Amazon S3 एक object-storage सेवा है, जिसमें data को bucket और key से रखा और प्राप्त किया जाता है। S3 Standard उच्च durability के लिए बनाया गया है, लेकिन durability का अर्थ zero risk, availability या backup नहीं है। Recovery के लिए versioning और अन्य controls configure करें।

02. Direct Client-to-S3 Upload with Presigned URLs

Proxying large file uploads through a Node.js or Fastify web server saturates event loop memory and network bandwidth. Generating a Presigned PUT URL delegates raw payload transmission straight to AWS S3.

A presigned URL is a bearer credential: anyone who obtains it can use it until expiry, within the signing principal's permissions. A presigned PUT can overwrite its target key. Use authorized, unpredictable keys and independently validate content and size.

03. S3 Multipart Upload Architecture

For large files, multipart upload sends parts independently and supports parallel transfer. Current documented part sizes are 5 MiB–5 GiB, with up to 10,000 parts and no minimum for the final part. Configure lifecycle cleanup for abandoned uploads.

04. Amazon CloudFront CDN & Origin Access Control (OAC)

CloudFront can serve cached content near viewers. Latency depends on network route and cache state. S3-to-CloudFront transfer is generally not charged as S3 internet egress, but S3 requests, CloudFront delivery, and related features still have costs. OAC signs S3 origin requests with SigV4.

05. Asynchronous Media Processing Pipeline

S3 Event Notifications trigger SQS Queues or Kafka Streams to orchestrate background FFmpeg transcoding workers without blocking client checkout or ingestion.

Notifications can be delivered more than once and are not guaranteed to arrive in order. Make workers idempotent and use object version IDs or event sequencers where appropriate.
